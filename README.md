# PVZ Garden checkpoint downloads

These are the frozen 2026-11-11 checkpoint archives. Open the [release page](https://github.com/Nicky-Dimes/pvz-garden-app/releases/tag/checkpoint-2026-11-11) for direct download links.

Start with PVZ_GARDEN_CLAUDE_HANDOFF.zip (26 MB). Upload it to Claude and say: Read CLAUDE_RESUME.md first.

The five PVZ_GARDEN_SOURCE_ART_XX_OF_05.zip archives are ordinary ZIPs containing different files. Download all five and extract each into the same destination directory as the main handoff, merging matching folders. READ_ME_FIRST.txt has full extraction instructions, and SHA256SUMS.txt contains SHA-256 checksums.

The full source tree is on the claude-handoff-2026-11-11 branch.
