PVZ Garden - frozen Claude handoff

1. Download PVZ_GARDEN_CLAUDE_HANDOFF.zip (26 MB). Upload this ZIP to Claude and say: Read CLAUDE_RESUME.md first.

2. PVZ_GARDEN_PLAYABLE.zip is the separate playable build. Extract it and follow its README.

3. The original source artwork is supplied as FIVE ordinary ZIP files named PVZ_GARDEN_SOURCE_ART_01_OF_05.zip through PVZ_GARDEN_SOURCE_ART_05_OF_05.zip. Download all five and extract each into the SAME destination directory as the main handoff. Each ZIP contains different files with the correct folder structure; merge matching folders. Together these contain exactly the same 846 entries as the original 437 MB PVZ_GARDEN_SOURCE_ART.zip mentioned in the project documentation. No reassembly command is needed.

The artwork was divided only for OneDrive transfer limits. The frozen code and artwork are unchanged.

After extracting the source art, the project helper tools/animation_restore_refs.py can restore redundant reference mirrors as described in CLAUDE_RESUME.md.
